ENGLAT PDF portable mode

While this file sits next to englat-pdf.exe, ENGLAT PDF keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the EnglatPdfData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move ENGLAT PDF with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\ENGLAT PDF and
%LOCALAPPDATA%\ENGLAT PDF) instead. If EnglatPdfData can't be written (for example on a read-only
drive), ENGLAT PDF says so and uses the per-user folders instead.
